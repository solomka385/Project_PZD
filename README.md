# Project_PZD

Учебный Python-проект с приложением `PZD_project.py` и набором зависимостей для запуска и экспериментов.

## Запуск

```bash
python PZD_project.py
```

Установить зависимости можно командой `pip install -r requirements.txt`.

## Безопасность

GitPython закреплён на версии `3.1.41` или новее для устранения CVE-2024-22190.
